# 声学模型说明

声学模型是语音识别必须的文件，需要集成打包到语音固件中。本文档整理了我司芯片对应的声学模型的名称和特点，用户可根据所选择的芯片型号、芯片或模块支持的Flash容量大小以及产品应用环境，选择合适的声学模型。声学模型可以在我司语音AI平台语言模型功能模块中选择并下载。
