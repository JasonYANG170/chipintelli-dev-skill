# 离在线大模型对话SDK版本介绍

## **初始版本：CI13XX\_SDK\_LLM\_AIoT\_V1.0.10**

该版本支持离线语音唤醒和命令词识别、VAD端点检测、离线语音上传、在线语音播放(mp3/pcm)、speex/opus编解码、OTA在线升级等功能
