# Speech API

离线语音算法SDK（CI-SDK-NN-ENC）提供了一套完整的离线语音降噪与音频处理接口，帮助开发者快速集成高性能语音交互功能。SDK 采用模块化设计，支持灵活配置，适用于智能家居、车载语音、消费电子等多种场景。
