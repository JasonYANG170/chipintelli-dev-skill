# 录音板使用说明

## 概述

在调试识别和优化识别效果过程中，需要对麦克风的语音输入进行录音，分析语音识别模块底噪是否正常，麦克风语音输入是否有外界引入的异常干扰。针对该问题，可以使用录音板对模块进行音频采集，针对采集的音频进行分析以判断是否有噪声或干扰。以下内容介绍如何使用录音板对模块进行音频采集。如用户想获取录音板，请点击 ☞[样品购买](http://mall.chipintelli.com/) 采购或联系我司商务人员。
