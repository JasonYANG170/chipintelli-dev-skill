# 声学模型说明

声学模型是语音识别系统中的核心组件，必须以固件.bin形式集成到设备中。为方便开发者选型，本文档描述了我司各个芯片系列对应的声学模型清单及其关键特性的查询流程及下载方法。在选择模型时，请结合目标芯片的型号、Flash存储容量以及实际应用场景进行综合评估，以选择最匹配的声学模型。

所有声学模型均可通过我司的【语音AI平台】中“语言模型开发”模块进行查询和下载。若对模型特性或集成方式存在疑问，建议参考平台提供的技术文档或联系[技术支持](https://document.chipintelli.com/%E8%81%94%E7%B3%BB%E6%88%91%E4%BB%AC/)。步骤如下：

1. 在浏览器输入并打开语音AI平台网址[aiplatform.chipintelli.com](https://aiplatform.chipintelli.com/begin)；

![image-20250923174714751](https://document.chipintelli.com/%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91/SDK/CI13XX%E8%8A%AF%E7%89%87SDK/CI-SDK-Offline/CI13XX_SDK_ASR_Offline_V2.2.0/API%E6%8C%87%E5%8D%97/%E8%AF%AD%E9%9F%B3%E8%AF%86%E5%88%AB%E6%B7%B1%E5%BA%A6%E5%BC%80%E5%8F%91%E8%BF%9B%E9%98%B6/img/%E5%A3%B0%E5%AD%A6%E6%A8%A1%E5%9E%8B%E8%AF%B4%E6%98%8E174714751.png)

2. 点击“功能开发”；

![image-20250923174753817](https://document.chipintelli.com/%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91/SDK/CI13XX%E8%8A%AF%E7%89%87SDK/CI-SDK-Offline/CI13XX_SDK_ASR_Offline_V2.2.0/API%E6%8C%87%E5%8D%97/%E8%AF%AD%E9%9F%B3%E8%AF%86%E5%88%AB%E6%B7%B1%E5%BA%A6%E5%BC%80%E5%8F%91%E8%BF%9B%E9%98%B6/img/%E5%A3%B0%E5%AD%A6%E6%A8%A1%E5%9E%8B%E8%AF%B4%E6%98%8E174753817.png)

3. 点击组件开发中的“语言模型开发”板块；

![image-20250923174825541](https://document.chipintelli.com/%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91/SDK/CI13XX%E8%8A%AF%E7%89%87SDK/CI-SDK-Offline/CI13XX_SDK_ASR_Offline_V2.2.0/API%E6%8C%87%E5%8D%97/%E8%AF%AD%E9%9F%B3%E8%AF%86%E5%88%AB%E6%B7%B1%E5%BA%A6%E5%BC%80%E5%8F%91%E8%BF%9B%E9%98%B6/img/%E5%A3%B0%E5%AD%A6%E6%A8%A1%E5%9E%8B%E8%AF%B4%E6%98%8E174825541.png)

4. 点击“+新建项目”；

![image-20250923174925556](https://document.chipintelli.com/%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91/SDK/CI13XX%E8%8A%AF%E7%89%87SDK/CI-SDK-Offline/CI13XX_SDK_ASR_Offline_V2.2.0/API%E6%8C%87%E5%8D%97/%E8%AF%AD%E9%9F%B3%E8%AF%86%E5%88%AB%E6%B7%B1%E5%BA%A6%E5%BC%80%E5%8F%91%E8%BF%9B%E9%98%B6/img/%E5%A3%B0%E5%AD%A6%E6%A8%A1%E5%9E%8B%E8%AF%B4%E6%98%8E174925556.png)

5. 项目名称随意输入即可，我这里输入“查询声学模型”；

![image-20250923174326777](https://document.chipintelli.com/%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91/SDK/CI13XX%E8%8A%AF%E7%89%87SDK/CI-SDK-Offline/CI13XX_SDK_ASR_Offline_V2.2.0/API%E6%8C%87%E5%8D%97/%E8%AF%AD%E9%9F%B3%E8%AF%86%E5%88%AB%E6%B7%B1%E5%BA%A6%E5%BC%80%E5%8F%91%E8%BF%9B%E9%98%B6/img/%E5%A3%B0%E5%AD%A6%E6%A8%A1%E5%9E%8B%E8%AF%B4%E6%98%8E174326777.png)

6. 应用场景根据您想开发的产品进行选择即可，这里以风扇为例；

![image-20250923174257368](https://document.chipintelli.com/%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91/SDK/CI13XX%E8%8A%AF%E7%89%87SDK/CI-SDK-Offline/CI13XX_SDK_ASR_Offline_V2.2.0/API%E6%8C%87%E5%8D%97/%E8%AF%AD%E9%9F%B3%E8%AF%86%E5%88%AB%E6%B7%B1%E5%BA%A6%E5%BC%80%E5%8F%91%E8%BF%9B%E9%98%B6/img/%E5%A3%B0%E5%AD%A6%E6%A8%A1%E5%9E%8B%E8%AF%B4%E6%98%8E174257368.png)

7. 选择您想查询的芯片系列和具体型号；

![image-20250923174454241](https://document.chipintelli.com/%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91/SDK/CI13XX%E8%8A%AF%E7%89%87SDK/CI-SDK-Offline/CI13XX_SDK_ASR_Offline_V2.2.0/API%E6%8C%87%E5%8D%97/%E8%AF%AD%E9%9F%B3%E8%AF%86%E5%88%AB%E6%B7%B1%E5%BA%A6%E5%BC%80%E5%8F%91%E8%BF%9B%E9%98%B6/img/%E5%A3%B0%E5%AD%A6%E6%A8%A1%E5%9E%8B%E8%AF%B4%E6%98%8E174454241.png)

8. 选择需要查询的国家或地区语言；

![image-20250923174548824](https://document.chipintelli.com/%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91/SDK/CI13XX%E8%8A%AF%E7%89%87SDK/CI-SDK-Offline/CI13XX_SDK_ASR_Offline_V2.2.0/API%E6%8C%87%E5%8D%97/%E8%AF%AD%E9%9F%B3%E8%AF%86%E5%88%AB%E6%B7%B1%E5%BA%A6%E5%BC%80%E5%8F%91%E8%BF%9B%E9%98%B6/img/%E5%A3%B0%E5%AD%A6%E6%A8%A1%E5%9E%8B%E8%AF%B4%E6%98%8E174548824.png)

9. 根据提示选择需要查询的模型类型；

![image-20250923175034663](https://document.chipintelli.com/%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91/SDK/CI13XX%E8%8A%AF%E7%89%87SDK/CI-SDK-Offline/CI13XX_SDK_ASR_Offline_V2.2.0/API%E6%8C%87%E5%8D%97/%E8%AF%AD%E9%9F%B3%E8%AF%86%E5%88%AB%E6%B7%B1%E5%BA%A6%E5%BC%80%E5%8F%91%E8%BF%9B%E9%98%B6/img/%E5%A3%B0%E5%AD%A6%E6%A8%A1%E5%9E%8B%E8%AF%B4%E6%98%8E175034663.png)

10. 根据提示选择操作类型，无需勾选“语言模型自动优化”；

![image-20250923175140498](https://document.chipintelli.com/%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91/SDK/CI13XX%E8%8A%AF%E7%89%87SDK/CI-SDK-Offline/CI13XX_SDK_ASR_Offline_V2.2.0/API%E6%8C%87%E5%8D%97/%E8%AF%AD%E9%9F%B3%E8%AF%86%E5%88%AB%E6%B7%B1%E5%BA%A6%E5%BC%80%E5%8F%91%E8%BF%9B%E9%98%B6/img/%E5%A3%B0%E5%AD%A6%E6%A8%A1%E5%9E%8B%E8%AF%B4%E6%98%8E175140498.png)

11. 点击继续；

![image-20250923175246628](https://document.chipintelli.com/%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91/SDK/CI13XX%E8%8A%AF%E7%89%87SDK/CI-SDK-Offline/CI13XX_SDK_ASR_Offline_V2.2.0/API%E6%8C%87%E5%8D%97/%E8%AF%AD%E9%9F%B3%E8%AF%86%E5%88%AB%E6%B7%B1%E5%BA%A6%E5%BC%80%E5%8F%91%E8%BF%9B%E9%98%B6/img/%E5%A3%B0%E5%AD%A6%E6%A8%A1%E5%9E%8B%E8%AF%B4%E6%98%8E175246628.png)

12. 点击“选择声学模型”后的问号中的“声学模型说明”即可查询模型列表；

![image-20250923175534180](https://document.chipintelli.com/%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91/SDK/CI13XX%E8%8A%AF%E7%89%87SDK/CI-SDK-Offline/CI13XX_SDK_ASR_Offline_V2.2.0/API%E6%8C%87%E5%8D%97/%E8%AF%AD%E9%9F%B3%E8%AF%86%E5%88%AB%E6%B7%B1%E5%BA%A6%E5%BC%80%E5%8F%91%E8%BF%9B%E9%98%B6/img/%E5%A3%B0%E5%AD%A6%E6%A8%A1%E5%9E%8B%E8%AF%B4%E6%98%8E175534180.png)

13. “模型列表”如下所示：

![image-20250923202518472](https://document.chipintelli.com/%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91/SDK/CI13XX%E8%8A%AF%E7%89%87SDK/CI-SDK-Offline/CI13XX_SDK_ASR_Offline_V2.2.0/API%E6%8C%87%E5%8D%97/%E8%AF%AD%E9%9F%B3%E8%AF%86%E5%88%AB%E6%B7%B1%E5%BA%A6%E5%BC%80%E5%8F%91%E8%BF%9B%E9%98%B6/img/%E5%A3%B0%E5%AD%A6%E6%A8%A1%E5%9E%8B%E8%AF%B4%E6%98%8E202518472.png)
