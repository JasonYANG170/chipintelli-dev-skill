# 从2.1.14迁移到2.2.0

CI130X\_SDK从2.0.10迁移到2.1.14，应用示例工程未做代码结构修改，没有API、配置宏等相关改动，把工程目录从旧SDK中 “CI13XX\_SDK\_ASR\_Offline\_V2.1.14\projects\xxx” 直接拷贝到新的SDK目录 “CI13XX\_SDK\_ASR\_Offline\_V2.2.0\projects\”下即可使用。
