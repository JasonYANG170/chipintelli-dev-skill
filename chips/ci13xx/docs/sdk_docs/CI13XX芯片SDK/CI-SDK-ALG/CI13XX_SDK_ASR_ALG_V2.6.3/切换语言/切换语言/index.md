# 切换语言

《软件开发》部分文档现在有两种语言的版本。如有出入，请以中文版本为准。

* 中文
* 英文

如下图所示，如果该文档两种语言版本均具备，可以通过点击文档上方的语言链接，轻松进行语言切换。
