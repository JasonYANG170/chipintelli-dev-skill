# 从2.4.18迁移到2.5.32

CI13XX\_SDK\_ASR\_ALG从2.4.18迁移到2.5.32，主要修改功能如下：

1. 解决doa+aec+cwsl, 学习出现复位问题
2. 解决2.5M模型识别响应慢的问题
3. 外部晶振默认频率修改为246M，内部晶振默认频率为200M
4. 多意图优化及响应速度的提升
5. 超慢语速识别效果提升;超快语速识别效果提升;两个字识别效果提升
6. DOA帧长统计内存优化
7. DOA效果提升(混响环境，办公室环境)
8. 单双mic高混响环境识别率达到90%
9. 解决垃圾词不生效问题
10. 单mic识别抗噪提升
11. 双mic盲源分离提升
12. 通话降噪算法优化
13. 事件检测算法更新
