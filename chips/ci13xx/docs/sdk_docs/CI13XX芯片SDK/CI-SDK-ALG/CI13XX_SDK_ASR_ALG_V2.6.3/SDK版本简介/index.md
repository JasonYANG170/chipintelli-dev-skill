# 离线语音算法SDK版本介绍

## **CI-SDK-ASR-ALG\_V2.6.3**

本次更新：

1. 解决自学习学习问题；

## **CI-SDK-ASR-ALG\_V2.5.32**

版本 2.5.32

本次更新：

1. 通话降噪算法优化。
2. 新增自然说+多意图。
3. 双mic盲源分离提升。
4. 优化双mic识别算法。
5. 单mic识别抗噪提升。
6. 解决垃圾词不生效bug。
7. 解决声纹稳定性问题。
8. 提升AEC打断效果，优化AEC算法。
9. 双mic盲源分离提升。
10. DOA效果提升(混响环境)；
11. 声源定位帧长统计内存优化。
12. 两个字识别效果提升。
13. 超快语速识别效果提升。
14. 超慢语速识别效果提升。
15. 多意图优化及响应速度的提升。
16. 外部晶振默认频率修改为246M，内部晶振默认频率为200M。
17. 声源定位帧长统计内存优化。
18. 解决2.5M模型识别响应慢的问题。

## **CI130X\_SDK\_ALG\_PRO\_V2.4.18**

版本 V2.4.18

本次更新：

1. 解决ASR云端通道bug。
2. 增大识别运算buffer和计算帧数。
3. DOA算法更新。
4. 自学习算法更新，修正自学习两遍失败bug。
5. 增大识别运算buffer和计算帧数。
6. 解决蓝牙配置宏默认错误打开，导致外部晶振未起效的bug。
7. 使用双mic算法开AEC时，默认关闭串口采音功能，并将采音串口配置参数开放。
8. 去掉AEC只有唤醒词打断限制，默认唤醒词和命令词都能打断。
9. 更新firmware参考\ir(红外)\firmware\asr里asr 923语音模型文件。
10. 解决降混响全频带处理参数配置不起效的问题。
11. 解决doa数据量化转换不起效问题解决。
12. 优化播报完，识别不稳定问题。
