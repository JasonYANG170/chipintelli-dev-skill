## Unified SDK Advantages

The CI13XX unified SDK supports both CI130X and CI13LC chips:
- Single SDK for all 2nd and 3rd gen chips
- All algorithm modules available (AEC, BF, DOA, Dereverb, AGC, DRC, EQ)
- Advanced features: TTS, VPR, NLP, sound event detection
- BLE support via ci_ble component
- IR support via ir_remote_driver
