# 算法概述

---

## 1. 概述

CI230X系列芯片具有较强的CPU运算能力，支持硬件NN加速，以及充足的RAM。能够完成一些常见的语音处理算法。主要包含了以下功能。使用者可以根据不同产品需求进行合适的选择。具体使用方式及适用场景可参考文档中相关章节。

| 算法名称 | 算法说明 |
| --- | --- |
| ASR | 语音识别 |
| doa | 波达方向估计 |
| dereverb | 去混响 |
| denoise | 降噪 |
| aec | 回声消除 |
| beamforming | 波束形成 |
| bss | 盲源分离 |
