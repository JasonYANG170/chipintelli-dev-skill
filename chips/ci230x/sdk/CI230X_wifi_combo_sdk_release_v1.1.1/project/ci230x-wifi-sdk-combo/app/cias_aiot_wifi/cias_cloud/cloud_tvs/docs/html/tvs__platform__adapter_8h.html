◆ tvs_platform_adaptor_load_preference

typedef const char*(* tvs_platform_adaptor_load_preference) (int *preference_size)

实现此接口，向TVS SDK提供读取持久化配置的能力。 一般在设备重启的时候，会回调此函数加载持久化配置的各项参数

参数
preference_size出参，代表当前持久化配置数据占用内存空间的总字节数
返回
当前系统的持久化配置数据，由此函数内部通过malloc在堆上申请内存，SDK调完此接口，将会调用free释放内存

◆ tvs_platform_adaptor_save_preference

typedef int(* tvs_platform_adaptor_save_preference) (const char *preference_buffer, int preference_size)

实现此接口，向TVS SDK提供保存持久化配置的能力。 SDK在各种配置参数的值改变的时候，会回调此函数，保存新的持久化配置

参数
preference_buffer带保存的持久化配置数据
preference_size当前持久化配置数据占用内存空间的总字节数
返回
0为保存成功，其他值为保存失败

◆ tvs_platform_adaptor_set_current_volume

typedef int(* tvs_platform_adaptor_set_current_volume) (int cloud_volume, int max_value, bool do_init)

实现此接口，向TVS SDK提供设置音量的能。 在TVS云端识别到用户的设置音量请求时，将下发音量设置命令，此函数将被回调

参数
cloud_volumeTVS云端下发的音量，需要转换为当前终端的实际音量，计算公式为(cloud_volume * 设备端平台支持的最大音量值 / 100)
max_valueSDK定义的最大音量值，固定为100
do_init取值true代表SDK当前正从preference中读取音量并设置（一般在调用tvs_platform_adapter_init过程中） 取值false代表SDK当前正响应语音对话指令，或者从APP一侧设置音量
返回
0为设置成功，其他值为设置失败

◆ tvs_platform_adaptor_soundcard_control

typedef int(* tvs_platform_adaptor_soundcard_control) (bool open, bool recorder, tvs_soundcard_config *sc_config)

实现此接口，向TVS SDK提供开启/关闭PCM语音录制、播放功能的能力；

参数
open开启/关闭
recorder设置为true，代表操作PCM录制功能, 设置为false，代表操作PCM播放功能
sc_config声卡参数, 只用于开启PCM录制或者播放的情况，其他情况都为NULL
返回
等于0代表操作成功，其他值代表操作失败

◆ tvs_platform_adapter_on_network_state_changed()

void tvs_platform_adapter_on_network_state_changed ( bool  connect)

当网络状态发生变化的时候，需要调用此函数通知SDK; 注意，在配网时终端作为AP的情况下，网络应该被认为是断开状态， 直到配网结束，终端退出AP模式，重新连上目标WIFI之后，才能调用此函数

参数
connect为true表示当前终端已经连上外网，为false表示当前网络断开
返回
