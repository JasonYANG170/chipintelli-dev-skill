◆ tvs_callback_on_terminal_sync

typedef void(* tvs_callback_on_terminal_sync) (const char *text, const char *token)

监听多端互动推送信息，一般是来自手机APP端的自定义消息。 实现此接口，可以接受这些自定义消息的推送，并跟进消息内容进行处理。

参数
text推送信息，一般是转义后的Json字符串，要与消息推送方约定格式。
token消息的唯一标识。
返回
无
