## 运行硬件要求

#### CPU

主频建议单核120mHZ以上；

支持架构：arm；

#### 内存

建议预留100k内存以上（不带声学前端）；

可通过裁剪支持更小内存的设备；

#### 存储

支持TF卡或者Flash，建议预留1M以上的空间；



## 编译环境要求

#### 操作系统

Window（需安装Cygwin/MinGW)、Linux

#### 编译环境

gcc for Arm、cmake

#### 第三方库

cjson、libspeex、lwip、mbedtls



## 支持操作系统

FreeRTOS、RT-Thread等RTOS系统



## 当前已适配平台

芯之联xr871、芯之联xr872、MTK mt7697D等
