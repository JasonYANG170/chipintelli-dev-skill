◆ tvs_mediaplayer_adapter_set_source

typedef int(* tvs_mediaplayer_adapter_set_source) (const char *song_url, const char *token, uint32_t offsetInSeconds)

当用户通过智能语音、媒体播控，或者在APP端推送媒体时，云端将媒体下发到设备端，SDK将回调此接口， 实现此接口，将下发的新媒体的流媒体url，以及媒体对应的唯一标识，和需要快进的进度设置给平台播放器， 准备开始播放

参数
song_url待播放的流媒体url。
token媒体对应的唯一标识。
offsetInSeconds如果此参数大于0，代表此媒体需要快进到offsetInSeconds秒处，再开始播放
返回
0代表成功，其他值代表失败
