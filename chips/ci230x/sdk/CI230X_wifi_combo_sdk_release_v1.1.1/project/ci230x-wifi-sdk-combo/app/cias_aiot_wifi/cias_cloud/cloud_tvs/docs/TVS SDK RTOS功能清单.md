# TVS SDK RTOS 功能清单

### 1、基础语音会话

- 在线语音会话（语音识别+语义理解+语音合成）
  流式语音输入，流式语音回复，通过单击按钮触发
- 多轮会话
- 语音Speex压缩
- 8K/16K录音配置

### 2、扩展会话能力

- 在线文本会话（语义理解+语音合成）
  文本输入，语音回复
- 明确意图会话（语义+语音合成）
  semantic输入，语音回复

### 3、通用技能支持

- 闲聊、百科、天气等播报类技能
- 闹钟/提醒
- 音乐、新闻、FM、儿歌、故事等媒体播放类技能
- 音量控制
- 本地播控功能，上一首/下一首切换

### 4、多端互动

- 自定义消息透传
  从APP端发送自定义消息，设备端透传
- 云端播控
  从APP端发起媒体点播、上一首/下一首、设置音量等功能
- 云端闹钟
  从APP端设置闹钟并推送到设备端

### 5.账号登陆

- 第三方帐号登陆
- 访客登陆

### 6、模式控制

- 儿童模式
- 自定义模式切换
