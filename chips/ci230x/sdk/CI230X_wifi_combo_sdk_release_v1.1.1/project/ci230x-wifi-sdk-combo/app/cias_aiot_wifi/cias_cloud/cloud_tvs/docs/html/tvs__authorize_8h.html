◆ tvs_authorize_set_client_id()

int tvs_authorize_set_client_id ( const char *  client_id)

设置新的client id，调用此函数将清除之前的authorize结果，之后将利用新的client id重新执行authorize操作；已过时；

参数
client_id这个ID可用由其他端（比如手机）利用QQ、微信账号或者第三方账号生成并传递到本终端， 也可以利用product id和dsn组合，根据终端账号方案决定
返回
0为成功，其他值为失败，错误码见TVS_API_ERROR_*
