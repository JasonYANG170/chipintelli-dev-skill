typedef int(* tvs_alert_adapter_delete) (tvs_alert_summary *alerts, int alert_count)

实现此接口，赋予SDK删除闹钟的能力

参数
alerts待删除闹钟概要，可以根据alert_token删除指定闹钟
alert_count待删除闹钟的个数
返回
0为删除闹钟成功，其他值为失败
