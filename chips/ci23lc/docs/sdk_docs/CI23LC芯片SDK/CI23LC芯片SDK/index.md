# SDK概述

---

## 1. 概述

目前CI23LC系列芯片的SDK仅有纯离线+BLE版本，如下：

* 纯离线+BLE SDK：CI23LC\_SDK\_BLE

该SDK可以到 ☞[启英泰伦语音AI平台](https://aiplatform.chipintelli.com/attachment) 资料库中下载并使用。
