# 启英物联小程序使用指南

## **一. 启英物联/启英智能设备 小程具体步骤如下：**

1. 微信，搜索 “*启英物联*” 或者”*AI语音智控*” 小程序
2. 打开蓝牙权限(部分手机需要开启位置权限)
3. 开启手机蓝牙
4. 添加设备，通过点击“＋”号，或者“添加设备”按键，进行添加设备
5. 进入扫描设备界面，点击扫描到的设备\*\* (目前该小程序支持的设备有：茶吧机，空调，灯，风扇…)
6. 确定连接设备
7. 设备命名
8. 连接成功，返回首页
9. 点击添加的设备即可进入设备操作界面
