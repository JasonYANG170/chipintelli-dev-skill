# 凭据配置 / Credential configuration

通过私有编译参数设置 CI230X 示例的 PROJECT_WIFI_SSID 和 PROJECT_WIFI_PASSWORD，默认值为空。

Configure PROJECT_WIFI_SSID and PROJECT_WIFI_PASSWORD through private compiler definitions for the CI230X Wi-Fi examples. Empty defaults contain no deployment credentials.

已公开的真实凭据仍须撤销或更换。历史重写不能清除其他人的克隆、Fork 或 GitHub 缓存。

Revoke or rotate real credentials that were exposed. Rewriting history does not remove other clones, forks, or GitHub caches.
