# 单麦语音主控

语音芯片既做语音识别，也做设备控制。语音芯片根据语音转化指令结果，通过语音芯片IO对设备做出相应的响应或控制。支持离线自然说及固定词条的识别、支持多意图理解功能、支持回声消除、支持自学习、多唤醒词切换等，亦可提供SDK及文档供开发者进行二次开发。目前，该方已在各种领域中得到量产应用，如风扇、空调、照明等。

## 离线产品方案概述

---

主控方案：很多时候，可以将启英泰伦的语音芯片作为MCU使用，将离线语音识别和控制功能都做在一个芯片上，这一方面降低了产品的成本，另一方面方案也可以更加小型化，我司提供以下几种主控方案供参考：
