# 单麦语音红外控制

语音芯片将采集的语音转化为指令后，根据识别指令发送对应的红外控制码对设备进行控制。支持市面上98%的空调控制，支持红外控制码的学习，支持小程序控制。支持离线自然说及固定词条的识别、支持多意图理解功能、支持自学习、多唤醒词切换等，亦可提供SDK及文档供开发者进行二次开发。目前，该方已在各种领域中得到量产应用，如空调、语音遥控器、风扇、照明、窗帘等。
