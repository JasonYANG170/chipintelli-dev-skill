# 双麦语音识别

语音芯片将采集的语音转化为指令，通过串口与电控板的MCU或其他设备进行通讯，MCU或设备接收到指令后做出相应的响应或控制，MCU或设备亦可发送指令给语音芯片进行语音播报等操作。支持离线自然说及固定词条的识别、支持多意图理解功能、支持自学习、多唤醒词切换；支持降混响、深度分离、声源定位等算法及各算法的组合，以满足不同应用场景的需求；亦可提供SDK及文档供开发者进行二次开发。目前，该方已在各种领域中得到量产应用，如风扇、晾衣杆、取暖桌、茶吧机、照明等。
