# 单麦语音AIOT

支持本地语音唤醒、离线自然说及固定词条的识别、支持多意图理解功能，可对接腾讯IOT云，涂鸦IOT云，腾讯TVS云，阿里IOT云等及客户自建的云平台，亦可提供SDK及文档供开发者进行二次开发。

## AIOT产品方案概述

本文档为用户介绍了启英泰伦用CI230X系列芯片开发的AIOT产品方案应用案例，用户可以查阅对应文档浏览相关信息，用于指导开发和产品生产。

**CI230X系列芯片支持的配网模式：**

* 蓝牙BLE配网模式（推荐使用）
* AP配网模式

**CI230X系列芯片已接入的IOT云：**

* **腾讯IOT云**：腾讯IOT相关的开发建议采用启英已开发好的WIFI SDK固件 ,直接烧入固件和鉴权信息便可接入腾讯IOT云，这样可以不仅可以降低开发成本，还能加速项目落地，将开发重心放在语音固件的开发，WiFi固件只做数据透传；“[离线语音&腾讯连连小程序IOT方案演示视频](https://document.chipintelli.com/%E8%A7%86%E9%A2%91%E6%95%99%E7%A8%8B/%E4%BA%A7%E5%93%81%E6%96%B9%E6%A1%88/%E6%96%B9%E6%A1%8804%EF%BC%9A%E7%A6%BB%E7%BA%BF%E8%AF%AD%E9%9F%B3%26%E8%85%BE%E8%AE%AF%E8%BF%9E%E8%BF%9E%E5%B0%8F%E7%A8%8B%E5%BA%8F%E6%96%B9%E6%A1%88/)”
* **涂鸦IOT云**：SDK已完涂鸦云的接入，并有产品落地，涂鸦相关的开发需要涂鸦商务深度配合，立项，创建产品等信息；所以客户在接入涂鸦云的时候，请和涂鸦商务或者我司商务人员沟通。“[离线语音&涂鸦APP IoT方案演示视频](https://document.chipintelli.com/%E8%A7%86%E9%A2%91%E6%95%99%E7%A8%8B/%E4%BA%A7%E5%93%81%E6%96%B9%E6%A1%88/%E6%96%B9%E6%A1%8803%EF%BC%9A%E7%A6%BB%E7%BA%BF%E8%AF%AD%E9%9F%B3%26%E6%B6%82%E9%B8%A6APP%20IoT%E6%96%B9%E6%A1%88/)”
* **腾讯TVS云**：腾讯TVS云接入会涉及到在线识别部分，以及播放在线资源的内容，开发难度较大，我司已完成云端接入和在线资源播放的功能，请和我司商务沟通后单独立项支持。“[离线语音&腾讯云小微在线语音方案演示视频](https://document.chipintelli.com/%E8%A7%86%E9%A2%91%E6%95%99%E7%A8%8B/%E4%BA%A7%E5%93%81%E6%96%B9%E6%A1%88/%E6%96%B9%E6%A1%8802%EF%BC%9A%E7%A6%BB%E7%BA%BF%E8%AF%AD%E9%9F%B3%26%E8%85%BE%E8%AE%AF%E4%BA%91%E5%B0%8F%E5%BE%AE%E5%9C%A8%E7%BA%BF%E8%AF%AD%E9%9F%B3%E6%96%B9%E6%A1%88/)”
* **阿里IOT云-飞燕**：SDK已完成阿里飞燕云基础的云端接入功能，需要进行项目开发请和我司商务沟通后单独立项支持。
* **京东云-小京鱼**：SDK已完成京东云基础的云端接入功能，需要进行项目开发请和我司商务沟通后单独立项支持。
