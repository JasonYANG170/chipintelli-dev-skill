# 产品方案开发

## 概述

本文档为用户介绍了启英泰伦产品方案开发的介绍文档和已完成的一些产品方案的应用案例，用户可以查阅对应文档浏览相关信息，用于指导开发和产品生产。如下：

* [单麦语音识别](https://document.chipintelli.com/%E4%BA%A7%E5%93%81%E6%96%B9%E6%A1%88%E5%BC%80%E5%8F%91/%E5%8D%95%E9%BA%A6%E8%AF%AD%E9%9F%B3%E8%AF%86%E5%88%AB/)：语音芯片将采集的语音转化为指令，通过串口与电控板的MCU或其他设备进行通讯，MCU或设备接收到指令后做出相应的响应或控制，MCU或设备亦可发送指令给语音芯片进行语音播报等操作。支持离线自然说及固定词条的识别、支持多意图理解功能、支持回声消除、支持自学习、多唤醒词切换等，亦可提供SDK及文档供开发者进行二次开发。目前，该方已在各种领域中得到量产应用，如风扇、晾衣杆、取暖桌、茶吧机、照明等。
* [双麦语音识别](https://document.chipintelli.com/%E4%BA%A7%E5%93%81%E6%96%B9%E6%A1%88%E5%BC%80%E5%8F%91/%E5%8F%8C%E9%BA%A6%E8%AF%AD%E9%9F%B3%E8%AF%86%E5%88%AB/)：语音芯片将采集的语音转化为指令，通过串口与电控板的MCU或其他设备进行通讯，MCU或设备接收到指令后做出相应的响应或控制，MCU或设备亦可发送指令给语音芯片进行语音播报等操作。支持离线自然说及固定词条的识别、支持多意图理解功能、支持自学习、多唤醒词切换；支持降混响、深度分离、声源定位等算法及各算法的组合，以满足不同应用场景的需求；亦可提供SDK及文档供开发者进行二次开发。目前，该方已在各种领域中得到量产应用，如风扇、晾衣杆、取暖桌、茶吧机、照明等。
* [单麦深度降噪语音识别](https://document.chipintelli.com/%E4%BA%A7%E5%93%81%E6%96%B9%E6%A1%88%E5%BC%80%E5%8F%91/%E5%8D%95%E9%BA%A6%E6%B7%B1%E5%BA%A6%E9%99%8D%E5%99%AA%E8%AF%AD%E9%9F%B3%E8%AF%86%E5%88%AB/)：语音芯片将采集的语音转化为指令，通过串口与电控板的MCU或其他设备进行通讯，MCU或设备接收到指令后做出相应的响应或控制，MCU或设备亦可发送指令给语音芯片进行语音播报等操作。支持基于深度神经网络降噪等智能算法过滤复杂背景噪音，提升识别效果。主要用于晾衣架、烟机等65dB以上大噪声环境中的识别及语音交互。
* [单麦语音主控](https://document.chipintelli.com/%E4%BA%A7%E5%93%81%E6%96%B9%E6%A1%88%E5%BC%80%E5%8F%91/%E5%8D%95%E9%BA%A6%E8%AF%AD%E9%9F%B3%E4%B8%BB%E6%8E%A7/)：语音芯片既做语音识别，也做设备控制。语音芯片根据语音转化指令结果，通过语音芯片IO对设备做出相应的响应或控制。支持离线自然说及固定词条的识别、支持多意图理解功能、支持回声消除、支持自学习、多唤醒词切换等，亦可提供SDK及文档供开发者进行二次开发。目前，该方已在各种领域中得到量产应用，如风扇、空调、照明等。
* [单麦语音红外控制](https://document.chipintelli.com/%E4%BA%A7%E5%93%81%E6%96%B9%E6%A1%88%E5%BC%80%E5%8F%91/%E5%8D%95%E9%BA%A6%E8%AF%AD%E9%9F%B3%E7%BA%A2%E5%A4%96%E6%8E%A7%E5%88%B6/)：语音芯片将采集的语音转化为指令后，根据识别指令发送对应的红外控制码对设备进行控制。支持市面上98%的空调控制，支持红外控制码的学习，支持小程序控制。支持离线自然说及固定词条的识别、支持多意图理解功能、支持自学习、多唤醒词切换等，亦可提供SDK及文档供开发者进行二次开发。目前，该方已在各种领域中得到量产应用，如空调、语音遥控器、风扇、照明、窗帘等。
* [单麦语音小程序](https://document.chipintelli.com/%E4%BA%A7%E5%93%81%E6%96%B9%E6%A1%88%E5%BC%80%E5%8F%91/%E5%8D%95%E9%BA%A6%E8%AF%AD%E9%9F%B3%E5%B0%8F%E7%A8%8B%E5%BA%8F/)：语音芯片集成了蓝牙模块，它将采集的语音转化为指令，通过蓝牙与其他蓝牙设备进行通信，实现对配对蓝牙设备的控制，同时，提供了配套的小程序。支持离线自然说及固定词条的识别、支持多意图理解功能、支持回声消除、支持自学习、多唤醒词切换等；亦可提供SDK及文档供开发者进行二次开发。目前，该方已在各种领域中得到量产应用，如风扇、晾衣杆、取暖桌、茶吧机、照明等。
* [单麦语音AIOT](https://document.chipintelli.com/%E4%BA%A7%E5%93%81%E6%96%B9%E6%A1%88%E5%BC%80%E5%8F%91/%E5%8D%95%E9%BA%A6%E8%AF%AD%E9%9F%B3AIOT/)：支持本地语音唤醒、离线自然说及固定词条的识别、支持多意图理解功能，可对接腾讯IOT云，涂鸦IOT云，腾讯TVS云，阿里IOT云等及客户自建的云平台，亦可提供SDK及文档供开发者进行二次开发。
* [双麦语音AIOT](https://document.chipintelli.com/%E4%BA%A7%E5%93%81%E6%96%B9%E6%A1%88%E5%BC%80%E5%8F%91/%E5%8F%8C%E9%BA%A6%E8%AF%AD%E9%9F%B3AIOT/)：支持本地语音唤醒、自然说及固定词条的识别、支持多意图理解功能；支持降混响、深度分离、声源定位等算法及各算法的组合，以满足不同应用场景的需求；亦可提供SDK及文档供开发者进行二次开发。可对接腾讯IOT云，涂鸦IOT云，腾讯TVS云，阿里IOT云等及客户自建的云平台。
* [离线TTS方案](https://document.chipintelli.com/%E4%BA%A7%E5%93%81%E6%96%B9%E6%A1%88%E5%BC%80%E5%8F%91/%E7%A6%BB%E7%BA%BFTTS%E6%96%B9%E6%A1%88/%E7%A6%BB%E7%BA%BFTTS%E6%96%B9%E6%A1%88%E6%A6%82%E8%BF%B0/): 语音合成（Text To Speech，TTS）技术将文本转化为声音，该方案可以实现无网络状态下，通过串口协议，将接收到的文本转换成语音播报，目前广泛应用于叫号系统，考勤机，玩具、地图导航等场景。基于我司CI1103、CI1302、CI1303、CI1306语音芯片开发的端侧语音合成模块，是一套极具性价比的语音合成方案。
