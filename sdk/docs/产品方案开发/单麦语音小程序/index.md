# 单麦语音小程序

语音芯片集成了蓝牙模块，它将采集的语音转化为指令，通过蓝牙与其他蓝牙设备进行通信，实现对配对蓝牙设备的控制，同时，提供了配套的小程序。支持离线自然说及固定词条的识别、支持多意图理解功能、支持回声消除、支持自学习、多唤醒词切换等；亦可提供SDK及文档供开发者进行二次开发。目前，该方已在各种领域中得到量产应用，如风扇、晾衣杆、取暖桌、茶吧机、照明等。
