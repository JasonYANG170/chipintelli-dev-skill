# 单麦深度降噪语音识别

语音芯片将采集的语音转化为指令，通过串口与电控板的MCU或其他设备进行通讯，MCU或设备接收到指令后做出相应的响应或控制，MCU或设备亦可发送指令给语音芯片进行语音播报等操作。支持基于深度神经网络降噪等智能算法过滤复杂背景噪音，提升识别效果。主要用于晾衣架、烟机等65dB以上大噪声环境中的识别及语音交互。
