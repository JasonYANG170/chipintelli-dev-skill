# 单麦语音识别

语音芯片将采集的语音转化为指令，通过串口与电控板的MCU或其他设备进行通讯，MCU或设备接收到指令后做出相应的响应或控制，MCU或设备亦可发送指令给语音芯片进行语音播报等操作。支持离线自然说及固定词条的识别、支持多意图理解功能、支持回声消除、支持自学习、多唤醒词切换等，亦可提供SDK及文档供开发者进行二次开发。目前，该方已在各种领域中得到量产应用，如风扇、晾衣杆、取暖桌、茶吧机、照明等。

## 离线产品方案概述

本文档为用户介绍了启英泰伦已完成的一些离线产品方案的应用案例，用户可以查阅对应文档浏览相关信息，用于指导开发和产品生产。目前分为以下几类：

---

​串口通讯方案：作为最简单最快捷的通讯方式，可以快速为您的产品增加离线语音识别功能，目前我司提供两类应用方案供选择：

* [纯离线语音串口通讯方案](https://document.chipintelli.com/%E4%BA%A7%E5%93%81%E6%96%B9%E6%A1%88%E5%BC%80%E5%8F%91/%E5%8D%95%E9%BA%A6%E8%AF%AD%E9%9F%B3%E8%AF%86%E5%88%AB/%E5%BA%94%E7%94%A8%E6%A1%88%E4%BE%8B/%E4%B8%B2%E5%8F%A3%E4%B8%8E%E7%94%B5%E6%8E%A7%E9%80%9A%E8%AE%AF%E6%96%B9%E6%A1%88-%E7%BA%AF%E7%A6%BB%E7%BA%BF%E8%AF%AD%E9%9F%B3/)：最常用的为家电增加语音控制的方案，通过串口的数据交互为产品增加语音识别及语音播放功能。
* [纯离线+蓝牙串口通讯方案](https://document.chipintelli.com/%E4%BA%A7%E5%93%81%E6%96%B9%E6%A1%88%E5%BC%80%E5%8F%91/%E5%8D%95%E9%BA%A6%E8%AF%AD%E9%9F%B3%E8%AF%86%E5%88%AB/%E5%BA%94%E7%94%A8%E6%A1%88%E4%BE%8B/%E4%B8%B2%E5%8F%A3%E4%B8%8E%E7%94%B5%E6%8E%A7%E9%80%9A%E8%AE%AF%E6%96%B9%E6%A1%88-%E7%BA%AF%E7%A6%BB%E7%BA%BF%E8%AF%AD%E9%9F%B3%2B%E8%93%9D%E7%89%99/)：采用启英泰伦的语音芯片，结合蓝牙芯片做成的集蓝牙音乐，蓝牙通话，小程序为一体的的产品应用案例。
* [命令词自学习方案开发](https://document.chipintelli.com/%E4%BA%A7%E5%93%81%E6%96%B9%E6%A1%88%E5%BC%80%E5%8F%91/%E5%8D%95%E9%BA%A6%E8%AF%AD%E9%9F%B3%E8%AF%86%E5%88%AB/%E5%BA%94%E7%94%A8%E6%A1%88%E4%BE%8B/%E5%91%BD%E4%BB%A4%E8%AF%8D%E8%87%AA%E5%AD%A6%E4%B9%A0%E6%96%B9%E6%A1%88%E5%BC%80%E5%8F%91/)：通过深度神经网络提取说话人语音的深度声学特征，注册存储为声纹模板，从而用客户自定义的声纹模板代替默认的命令词指令。
