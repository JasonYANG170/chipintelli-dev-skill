# 关于本指南

本指南为 CI13XX系列芯片 官方应用软件开发的配套文档。

CI13XX系列芯片是启英泰伦研发的新一代高性能神经网络智能语音芯片，集成了我司自研的脑神经网络处理器BNPU V3和CPU内核。

CI-SDK-Offline 即启英泰伦 **离线语音识别软件开发包** ，可为在 Windows 系统上开发 CI13XX 系列应用程序提供工具链、API和组件等支持。
