# 离线语音识别SDK（CI-SDK-ASR-Offline）

---

## **概述**

目前CI13LC系列芯片的离线语音识别SDK（CI-SDK-ASR-Offline）具体发布版本为：CI13LC\_SDK\_ASR\_Offline\_V2.0.15

主要针对纯离线语音识别与简单应用场景，例如智能家居等，支持的音频前端算法有：

* ASR（Automatic Speech Recognition，自动语音识别），☞[《语音识别使用说明》](https://document.chipintelli.com/%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91/SDK/CI13LC%E8%8A%AF%E7%89%87SDK/CI-SDK-Offline/CI13LC_SDK_ASR_Offline_V2.0.15/API%E6%8C%87%E5%8D%97/%E7%AE%97%E6%B3%95%E4%BD%BF%E7%94%A8%E8%AF%B4%E6%98%8E/%E8%AF%AD%E9%9F%B3%E8%AF%86%E5%88%AB%E4%BD%BF%E7%94%A8%E8%AF%B4%E6%98%8E/)
* CWSL（Command Word Self-Learning，离线命令词自学习），☞[《离线命令词自学习使用说明》](https://document.chipintelli.com/%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91/SDK/CI13LC%E8%8A%AF%E7%89%87SDK/CI-SDK-Offline/CI13LC_SDK_ASR_Offline_V2.0.15/API%E6%8C%87%E5%8D%97/%E7%AE%97%E6%B3%95%E4%BD%BF%E7%94%A8%E8%AF%B4%E6%98%8E/%E7%A6%BB%E7%BA%BF%E5%91%BD%E4%BB%A4%E8%AF%8D%E8%87%AA%E5%AD%A6%E4%B9%A0%E4%BD%BF%E7%94%A8%E8%AF%B4%E6%98%8E/)
