# CI13LC 系列芯片SDK

目前CI13LC系列芯片的SDK根据不同应用场景有如下版本分类：

## 1. [离线语音识别SDK ：CI-SDK-ASR-Offline](https://document.chipintelli.com/%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91/SDK/CI13LC%E8%8A%AF%E7%89%87SDK/CI-SDK-Offline/)

注意

SDK发布版本格式：CI13LC\_SDK\_ASR\_Offline\_Vx.x.x

主要针对纯离线简单应用场景，例如智能家居等，支持的音频前端算法有：

* ASR（Automatic Speech Recognition，自动语音识别）
* CWSL（Command Word Self-Learning，离线命令词自学习）

---

备注

该版本SDK可以到 ☞[启英泰伦语音AI平台](https://aiplatform.chipintelli.com/attachment) 开发资料板块中进行下载使用。

## 2. [语音通话降噪SDK ：CI-SDK-NN-ENC](https://document.chipintelli.com/%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91/SDK/CI13LC%E8%8A%AF%E7%89%87SDK/CI-SDK-NN-ENC/)

注意

SDK发布版本格式：CI13LC\_SDK\_NN\_ENC\_Vx.x.x

主要针对降噪等应用场景，支持的音频前端算法有：

* NN DENOISE（Neural Network Denoise，神经网络降噪）
* ALC（Automatic Level Control，自动电平控制）
* AHS（Acoustic Howling Suppression，啸叫抑制）
* AGC（Automatic Gain Control，自动增益控制）
* EQ（Equalizer，均衡器）

---

备注

该版本SDK可以到 ☞[启英泰伦语音AI平台](https://aiplatform.chipintelli.com/attachment) 开发资料板块中进行下载使用。
