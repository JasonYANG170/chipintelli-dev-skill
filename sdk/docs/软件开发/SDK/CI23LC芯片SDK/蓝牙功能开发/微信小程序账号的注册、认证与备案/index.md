# 微信小程序账号的注册，认证与备案

## 1. 小程序账号注册

小程序☞[账号注册流程](https://kf.qq.com/faq/170109iQBJ3Q170109JbQfiu.html)

‌小程序账号主体主要分为个人小程序和企业小程序，可根据自身需求选择账号主体类型。

‌个人小程序‌：注册主体为个人，使用个人身份证进行注册。注册流程相对简单，只需提供个人身份信息验证即可‌。

‌企业小程序‌：注册主体为企业或组织，需要提供营业执照或组织代码证。注册流程较为复杂，需要提供管理者身份信息、企业各项资质、对公账号等一系列证明材料，并支付300元/年的认证费用‌。

功能区别：

‌个人小程序‌：功能限制较多，例如不支持微信支付、无法开通附近的小程序功能、不支持卡券包权限、无法获取用户手机号等信息授权‌。

‌企业小程序‌：功能较为完善，支持微信支付、卡券包权限、获取用户手机号等功能，适合商业运营和品牌推广‌。

## 2. 小程序微信认证

小程序☞[微信认证](https://kf.qq.com/product/wx_xcx.html#hid=2131)

新注册的小程序需进行主体验证和微信认证，否则无法发布线上小程序。

小程序账号需要年审认证，个人小程序‌30元一年，企业小程序‌300元一年。

小程序未年审认证的影响：

‌个人类账号‌：如果个人类账号未在认证到期前完成年审，平台将会回收账号的“被搜索、分享”能力‌。

‌非个人类账号‌：如果非个人类账号未在认证到期前完成年审，将无法发布新版本，同时平台也会回收账号的“被搜索、分享”能力。如果逾期1个月仍未完成年审，将影响账号的新用户访问和支付功能‌。

## 3. 小程序备案

根据微信平台的规定，微信小程序必须完成备案后才能发布和上架。

小程序☞[备案操作指引](https://developers.weixin.qq.com/miniprogram/product/record_guidelines.html)
