## 2. 发布操作步骤如下：

### 2.1. 使用微信开发者工具完成开发后，进行相关设置并上传代码

**步骤1：登录微信账号和小程序AppId设置**

![9](https://document.chipintelli.com/%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91/SDK/CI23LC%E8%8A%AF%E7%89%87SDK/%E8%93%9D%E7%89%99%E5%8A%9F%E8%83%BD%E5%BC%80%E5%8F%91/img/%E5%8F%91%E5%B8%83%E7%BB%86%E8%8A%82-1.png)

* **2: 填写代码要上传到小程序的AppId**。
* **1: 登录微信账号，该微信账号需有该小程序账号的开发者权限**。

**步骤2：进行本地设置并上传代码**

![9](https://document.chipintelli.com/%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91/SDK/CI23LC%E8%8A%AF%E7%89%87SDK/%E8%93%9D%E7%89%99%E5%8A%9F%E8%83%BD%E5%BC%80%E5%8F%91/img/%E5%8F%91%E5%B8%83%E7%BB%86%E8%8A%82-2.png)

### 2.2. 选择更新类型并填写版本信息后上传代码

![9](https://document.chipintelli.com/%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91/SDK/CI23LC%E8%8A%AF%E7%89%87SDK/%E8%93%9D%E7%89%99%E5%8A%9F%E8%83%BD%E5%BC%80%E5%8F%91/img/%E5%8F%91%E5%B8%83%E7%BB%86%E8%8A%82-3.png)

### 2.3. 将上传的代码提交审核/设为体验版本

* #### 使用微信登录[微信公众平台](https://mp.weixin.qq.com/)
* #### 成功登录微信公众平台后，在版本管理中可以看到上传的开发版本代码，点击提交审核

![9](https://document.chipintelli.com/%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91/SDK/CI23LC%E8%8A%AF%E7%89%87SDK/%E8%93%9D%E7%89%99%E5%8A%9F%E8%83%BD%E5%BC%80%E5%8F%91/img/%E5%8F%91%E5%B8%83%E7%BB%86%E8%8A%82-4.png)

* #### 体验版本：建议在发布线上版本前使用体验版进行小程序功能测试通过后再发布
