# 企业认证

平台用户账号注册后，默认为普通用户；当然，用户也可免费升级为企业用户。平台区分普通用户和企业用户的目的在于为不同类型的用户提供个性化的体验和服务，以满足用户不同的需求和期望，并最大化地发挥各自的优势。

如需开通，可通过“企业认证”成为企业用户，注册步骤如下：

## 1、进入企业认证页面

第一步：点击语音AI平台最右上角的用户头像图标，在弹出页点击“企业认证”;

![](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/%E4%BC%81%E4%B8%9A%E8%AE%A4%E8%AF%81/img/%E4%BC%81%E4%B8%9A%E8%AE%A4%E8%AF%81-new-1.png)

## 2、提交审核材料

第二步：如下图所示，填写相关信息，并上传相关资料后，点击“提交认证”按钮后，等待我司人员审核（审核时间预计一天左右）；

![](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/%E4%BC%81%E4%B8%9A%E8%AE%A4%E8%AF%81/img/%E4%BC%81%E4%B8%9A%E8%AE%A4%E8%AF%81-new-2.png)

## 3、通过企业认证审核

第三步：审核完成后，我司技术人员会为通过认证的用户开通企业用户相应权限。
