# 组件开发

“组件开发”板块主要用于生成语言模型(ASR)和播报音音频；首先，使用本板块的功能前，用户需要获取到SDK开发包。下面将介绍每个功能的具体使用步骤。

## 1、语言模型开发

用户在获取到SDK开发包之后，可以替换原有的ASR语言模型组件和声学模型，进行命令词的更改与声学模型升级等操作；帮助用户快速开发新固件。该功能具体操作步骤请参阅“[平台产品开发流程指引](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0%E4%BD%BF%E7%94%A8%E6%8C%87%E5%8D%97/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0%E4%BA%A7%E5%93%81%E5%BC%80%E5%8F%91%E6%B5%81%E7%A8%8B%E6%8C%87%E5%BC%95/)”。

![](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/%E5%8A%9F%E8%83%BD%E5%BC%80%E5%8F%91/%E7%BB%84%E4%BB%B6%E5%BC%80%E5%8F%91/img/%E5%8A%9F%E8%83%BD%E5%BC%80%E5%8F%91-8.png)

## 2、播报音合成

用户在得到SDK开发包之后，可以替换原有的播报音音频，进行个性化的播报音定制与合成；帮助用户快速开发新固件。该功能具体操作步骤请参阅“产品开发流程指引”。

![](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/%E5%8A%9F%E8%83%BD%E5%BC%80%E5%8F%91/%E7%BB%84%E4%BB%B6%E5%BC%80%E5%8F%91/img/%E5%8A%9F%E8%83%BD%E5%BC%80%E5%8F%91-9.png)

## 3、语言模型优化

[★仅限企业用户](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/%E4%BC%81%E4%B8%9A%E8%AE%A4%E8%AF%81/%E4%BC%81%E4%B8%9A%E8%AE%A4%E8%AF%81/)

若用户在对具体开发的语音识别产品进行测试发现识别效果有不佳的情况，可在语言模型优化功能中对包括“唤醒词”、“命令词”在内的所有词条进行识别上的调优；提交后平台将自动完成调优并反馈结果。该功能具体操作步骤请参阅“产品开发流程指引”。
