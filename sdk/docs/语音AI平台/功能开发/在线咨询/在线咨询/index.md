# 在线咨询

启英泰伦语音AI平台搭载了可实时在线咨询的客服机器人，能提供更快捷、更方便、更具个性化的客户服务体验。该客服机器人可以全天候帮助您快速定位问题并提供标准答案，也可以为您提供一对一专业解答、帮助和指导，从而提高问题解决效率。启英泰伦客服机器人旨在帮助客户更好地与企业互动，提升客户满意度，促进业务发展。

## 1、客服机器人

网页打开☞[启英泰伦语音AI平台](http://aiplatform.chipintelli.com/)，进入“功能开发”首页；如图，页面右侧悬浮的则是可实时在线咨询的客服机器人；点击进入对话窗口。
