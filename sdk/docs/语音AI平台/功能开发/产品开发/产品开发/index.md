# 产品开发

启英泰伦语音AI平台的“产品开发”板块对于产品开发人员来说，无需编写代码，可以快速将自己的想法转化为产品固件或SDK，从而加快产品上线速度。即使是非技术人员也能参与语音识别产品的开发，降低了技术门槛，从而节省了时间和成本。

本板块主要分为以下几个功能：

* 产品固件及SDK深度开发
* 演示固件快速开发

## 1、产品固件及SDK深度开发

用户可在“产品固件及SDK深度开发”功能中针对具体芯片开发套件进行在线开发量产固件，参数可配，协议自定，亦可获取SDK进行离线深度可编程开发；该功能具体操作步骤请参阅“[产品开发流程指引](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0%E4%BD%BF%E7%94%A8%E6%8C%87%E5%8D%97/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0%E4%BA%A7%E5%93%81%E5%BC%80%E5%8F%91%E6%B5%81%E7%A8%8B%E6%8C%87%E5%BC%95/)”。

## 2、演示固件快速开发

“演示固件快速开发”功能可以让语音固件使用默认配置十分钟内快速生成，让用户能够快速体验到属于自己产品的识别效果，让产品落地更快速；新人推荐先从此入口进行语音产品的入门开发。该功能具体操作步骤请参阅“[产品开发流程指引](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0%E4%BD%BF%E7%94%A8%E6%8C%87%E5%8D%97/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0%E4%BA%A7%E5%93%81%E5%BC%80%E5%8F%91%E6%B5%81%E7%A8%8B%E6%8C%87%E5%BC%95/)”。

## 3、固件调优

“固件调优”功能可用于优化与定制产品原有语音固件的语音识别性能，支持用户依照实际应用需求，灵活调整相关设置。用户可通过精细调控阈值和计数参数，显著提升产品的识别准确率与响应速度，优化交互体验。
同时，用户能便捷地修改唤醒词、命令词以及播报音内容，这些调整让设备更贴合个人使用习惯与所处环境的需求。凭借“固件调优”功能，用户不仅能够实现个性化语音识别能力的进阶，还能全方位增强产品的整体使用体验，提高工作效率。该功能具体操作步骤请参阅“[产品开发流程指引](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0%E4%BD%BF%E7%94%A8%E6%8C%87%E5%8D%97/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0%E4%BA%A7%E5%93%81%E5%BC%80%E5%8F%91%E6%B5%81%E7%A8%8B%E6%8C%87%E5%BC%95/)”。
