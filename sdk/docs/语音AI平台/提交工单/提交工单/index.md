# 提交工单

## 1、概述

在用户服务过程中，当您遇到的问题不能简易的处理时，可以通过我司平台提供的“提交工单”在线客服系统进行问题工单提交和转流给相关人员进行处理，平台会在规定工作日内进行答复处理。我司依据工单的内容将该工单进行了分类，方便用户进行针对性提问与之前经验QA自寻。

![](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/%E6%8F%90%E4%BA%A4%E5%B7%A5%E5%8D%95/img/%E6%8F%90%E4%BA%A4%E5%B7%A5%E5%8D%95-1.png)

## 2、工单分类

我司工单按照所属业务分为了语言模型问题、语音合成问题、定制固件问题、语言模型优化问题、平台使用问题、SDK相关问题、识别优化问题、结构设计问题、测试相关问题、性能相关问题、芯片和模块、开发方案和商务问题等十三大类工单类型。用户可按分类进行过往QA查询和问题提交。如下图所示：

![](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/%E6%8F%90%E4%BA%A4%E5%B7%A5%E5%8D%95/img/%E6%8F%90%E4%BA%A4%E5%B7%A5%E5%8D%95-2.png)

## 3、提交工单

为使我司工作人员尽快解决您的问题，用户需在提交工单的时候准确描述所遇到的问题，为了方便我司工作人员沟通，建议用户在工单右侧填写自己的联系方式，如下图所示：
