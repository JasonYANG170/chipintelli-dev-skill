# 样品采购

## 1、点击样品采购

点击“样品采购”按钮，则会跳转到文档中心“样品和批量采购”页面；“样品采购”功能为用户提供了芯片模块产品的购买途径，如下图所示：

![](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/%E6%A0%B7%E5%93%81%E9%87%87%E8%B4%AD/img/%E6%A0%B7%E5%93%81%E9%87%87%E8%B4%AD-1.png)

## 2、进入文档中心介绍页

具体所售商品请点击“样品购买”或扫描图中二维码进行查看并挑选购买。

![](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/%E6%A0%B7%E5%93%81%E9%87%87%E8%B4%AD/img/%E6%A0%B7%E5%93%81%E9%87%87%E8%B4%AD-2.png)

## 3、前往商城购买

用户可以按照页面的说明，根据自己的需求购买模块和芯片等产品，如用户需要购买大量模块或芯片，请通过页面中的联系方式联系我们。商城界面如下图：

![](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/%E6%A0%B7%E5%93%81%E9%87%87%E8%B4%AD/img/%E6%A0%B7%E5%93%81%E9%87%87%E8%B4%AD-3.png)
