# 语音AI平台概述

## 1 语音AI平台简介

成都启英泰伦科技有限公司语音AI平台，是我司为用户提供的一整套基于我司智能语音芯片方案的功能开发及管理平台，平台网址为：☞[http://aiplatform.chipintelli.com](http://aiplatform.chipintelli.com/)。该平台包含了功能开发、开发资料、提交工单、文档中心、样品采购、联系方式等功能。用户可以登录到该平台，使用本文中介绍的各项功能，结合我司智能语音芯片和对应的SDK开发包进行方案开发。平台提供的各项功能方便快捷，可以帮助用户节省方案开发时间，保障开发方案的性能，提升开发效率。

该平台主要有以下功能板块：

1. ☞[功能开发](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/%E5%8A%9F%E8%83%BD%E5%BC%80%E5%8F%91/%E5%BC%80%E5%8F%91%E6%96%87%E6%A1%A3/%E5%BC%80%E5%8F%91%E6%96%87%E6%A1%A3/)；
2. ☞[开发资料](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/%E5%BC%80%E5%8F%91%E8%B5%84%E6%96%99/%E5%BC%80%E5%8F%91%E8%B5%84%E6%96%99/)；
3. ☞[视频教程](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/%E8%A7%86%E9%A2%91%E6%95%99%E7%A8%8B/%E8%A7%86%E9%A2%91%E6%95%99%E7%A8%8B/)；
4. ☞[提交工单](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/%E6%8F%90%E4%BA%A4%E5%B7%A5%E5%8D%95/%E6%8F%90%E4%BA%A4%E5%B7%A5%E5%8D%95/)；

## 2 平台基本功能操作介绍

用户在浏览器中输入☞[启英泰伦语音AI平台](http://aiplatform.chipintelli.com/)网址(aiplatform.chipintelli.com)后，即可进入“登陆注册”界面，首次登陆该网址点击“创建”账号注册新用户，老用户直接输入账号、密码以及验证码后点击“登陆”即可，如下图所示：

![账号登陆1](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/img/%E8%B4%A6%E5%8F%B7%E7%99%BB%E9%99%86-2.png)

新用户根据页面提示，进行简单注册登陆后即可正式进入“语音AI平台”，注册权限分为“普通用户”和“企业用户”，如下图所示：

* 普通用户注册

![账号登陆2](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/img/%E8%B4%A6%E5%8F%B7%E7%99%BB%E9%99%86-3.png)

* 企业用户注册

![账号登陆3](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/img/%E8%B4%A6%E5%8F%B7%E7%99%BB%E9%99%86-4.png)

注册完成后在登陆界面输入正确的账号及密码即可；接下来，用户就可以正式开始体验语音AI平台。
