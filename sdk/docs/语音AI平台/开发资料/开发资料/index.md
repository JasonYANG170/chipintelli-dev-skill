# 开发资料

开发资料中包含了我司模组硬件设计和软件开发所需的资料，并且提供在线下载。

## 1、进入开发资料

用户可以点击顶部菜单中的“开发资料”进入该功能模块，如下图所示：

![](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/%E5%BC%80%E5%8F%91%E8%B5%84%E6%96%99/img/%E5%BC%80%E5%8F%91%E8%B5%84%E6%96%99-new-1.png)

## 2、搜索下载

用户可以点击“标签”选择欲查看的芯片系列文档，可以点击“分类”，查看对应类型的文档，可选择的分类有芯片数据手册、硬件设计资料、开发工具及手册、应用指南、第三方资料、外网器件兼容列表、固件、红外空调伴侣SDK，均用于开发使用；用户也可以进行搜索关键字找到合适的文档（该分类目录可能会不定期更新）。如下图所示：

![](https://document.chipintelli.com/%E8%AF%AD%E9%9F%B3AI%E5%B9%B3%E5%8F%B0/%E5%BC%80%E5%8F%91%E8%B5%84%E6%96%99/img/%E5%BC%80%E5%8F%91%E8%B5%84%E6%96%99-new-2.png)
