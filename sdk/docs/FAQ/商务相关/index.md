# 商务相关

## 请问如何获取公司最新信息？

关于公司的最新新闻，您可以登录☞[启英泰伦官网](http://www.chipintelli.com) 或微信公众号“启英泰伦”了解。

关于公司的产品信息，您可以使用本文档中心进行了解。

您也可以关注公司不定期在线上或线下组织的各类活动、研讨会、技术沙龙等，了解公司最新的产品和技术信息。
